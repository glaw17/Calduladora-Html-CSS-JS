#  Calculadora Dinâmica

Uma calculadora web interativa e dinâmica desenvolvida com **HTML5**, **CSS3** e **JavaScript**, com suporte a operações aritméticas fundamentais, potenciação (incluindo expoentes negativos).

---

## 🚀 Funcionalidades

- ➕ **Soma, Subtração, Multiplicação e Divisão**
- ⚡ **Potenciação**: Suporte a cálculo de potências com expoentes inteiros positivos e negativos.


---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica e formulários.
- **CSS3**: Estilização.
- **JavaScript**: Eventos e lógica matemática.

---

## 💻 Como Executar o Projeto

1. Baixe os arquivos do repositório (ou faça o `git clone`).
2. Abra o arquivo `index.html` em qualquer navegador web.
